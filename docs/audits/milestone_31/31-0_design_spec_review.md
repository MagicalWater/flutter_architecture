# Milestone 31 — Design Spec Review

## Findings

- P1：完整規則若同時存在Guide與Skill會形成雙重authority。Resolved：Skill為executable owner，governance document只作人類總覽。
- P1：Skill若自行取代repository policy會產生反向authority。Resolved：`AGENTS.md`保留強制入口與最高階禁止事項。
- P1：Level 0／1可能被過度治理。Resolved：加入mandatory／optional／forbidden矩陣與anti-over-governance scenarios。
- P1：Milestone 30 status仍有stale routing。Resolved in plan：納入authority修正與checker regression。

## Disposition

Design Spec accepted。Open P0 = 0；Open P1 without disposition = 0。
