# Roadmap Candidates

本文件只保存尚未核准為 active milestone、但已有具體價值與邊界的候選方向。Completed / promoted 工作不在此保存 historical artifact 清單。

## Candidate — Additional Platform Support

候選範圍：Web、Windows、macOS、Linux runner、artifact 與 runtime verification。

目前 Android / iOS 為 Supported；其他平台仍須依實際 scaffold、artifact、runtime smoke、plugin support 與維護成本獨立評估，不因 dependency 或 conditional implementation 存在就宣稱 Supported。

## Disposition — Documentation Knowledge Expansion

大型 documentation expansion 不是 current candidate。除非出現新的可驗證知識缺口與明確使用者價值，不以文件數、metadata 年齡或「補完整」為理由重啟大型文件工程。

## Promotion Rule

Candidate 提升為 active 前只需依 `governing-template-development` 的 lowest-sufficient classification 決定必要 artifact；不得預設一定建立 Milestone / Design / Plan。

其他未具體化 ideas 與 explicit non-goals 由 `docs/backlog.md` 保存。
